Я загружу:
Несколько чужих готовых вариантов (Word-файлы) — это примеры структуры, оформления, формул и графиков.
Свой Excel-файл (Таблица 1 — мой индивидуальный вариант с данными).
Твоя задача — сделать полностью новую, оригинальную работу по моему варианту, ориентируясь на структуру примеров.
🔎 ЭТАП 1. ПРОВЕРКА
Сначала:
Проверить все расчёты.
Проверить формулы.
Проверить индексы, дроби, проценты.
Найти возможные ошибки, опечатки, логические несоответствия.
Убедиться, что расчёты корректны по моим данным из Excel.
Если есть ошибки — исправить.
📊 ЭТАП 2. РАСЧЁТЫ
Все вычисления выполнять строго по моим данным.
Никакие цифры из чужих вариантов не использовать.
Все формулы применять корректно.
Промежуточные вычисления должны сходиться.
Результаты округлять аккуратно (без математических ошибок).
🧮 ФОРМУЛЫ
Все формулы оформить через встроенный редактор формул Word (OMML):
дроби (через нормальную математическую запись)
индексы (q₀, q₁, p₀ и т.д.)
средние значения (x̄)
суммы Σ
степени
корни
Никаких текстовых формул вида:
(600×5,50 + 900×0,50) / (600×5,50 + 800×0,50)
Только профессиональный математический формат Word.
📑 ТАБЛИЦЫ
Без пустых ячеек.
Простые грницы.
Аккуратноевыравнивание.
Полностью заполненные поля.
📈 ГРАФИКИ
Добавить все графики, которые есть в примерах:
столбчатые
линейные
динамиеские
индексные (если предусмотрены)
Требования к графикам:
Чёрно-белые.
Без цветных заливок.
Корректные подписи осей.
Названия графиков.
Логичное размещение в документе.
📝 ВЫВОДЫ
Очень важно:
Выводы должны быть написаны так, как пишет студент.
Простым академическим языком.
Без сложных научных оборотов.
Без «машинного» стиля.
Каждый раз формулировки должны отличаться.
Не копировать текст из чужих вариантов.
Не использовать одинаковые шаблонные фразы.
Выводы должны быть:
Развёрнутые.
Подробные.
С анализом чисел.
С интерпретацией процентов.
С пояснением, что означает каждый коэффициент, индекс или средняя величина.
Строго по результатам расчётов.
Чуть больше текста, чем в примерах (преподаватель любит подробность и точность).
🎓 ОФОРМЛЕНИЕ
Шрифт: Times New Roman
Основной текст: 14
Заголовки: 16
Цвет текста: только чёрный
Без декоративных элементов
Без лишних пустых строк
Без пустых страниц
Строго аккуратный формат
👤 ИМЯ В ДОКУМЕНТЕ
В титульном листе вместо имени студента указать:
ИМЯ ФАМИЛИЯ
Чтобы потом можно было вручную заменить.
Преподаватель остаётся тем же.
📦 ФИНАЛ
В конце выдать полностью готовый Word-файл (.docx):
С исправленными формулами (OMML)
С корректными таблицами
С добавленными графиками
С подробными выводами
Полностью готовый к печати
Я должен просто скачать файл и распечатать его без доработок.
Работа должна выглядеть как оригинальная, выполненная студентом по своему варианту, а не как копия чужого файла.
